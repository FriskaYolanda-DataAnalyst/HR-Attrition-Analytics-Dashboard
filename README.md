## 📌 Project Overview
Proyek ini menganalisis data retensi karyawan dari 1.470 entitas untuk mengidentifikasi pola pengunduran diri (*attrition*). Dashboard ini dirancang untuk membantu tim HR melakukan pengambilan keputusan berbasis data terkait strategi retensi.

## 🛠️ Tech Stack & Methodology
* **Tools:** Microsoft Excel (Power Query, Pivot Tables, Slicers).
* **Data Cleaning:** Menghapus duplikat dan standarisasi format mata uang.
* **Feature Engineering:** Membuat kategori *Salary Group* dan *Distance Grouping*.
* **Connectivity:** Mengintegrasikan semua visualisasi melalui *Report Connections* agar dashboard responsif terhadap filter.

## 🔍 Key Findings
* **Attrition Rate:** Rata-rata perusahaan berada di angka **16,12%**.
* **High-Risk Segment:** Kelompok **Low Income** memiliki risiko keluar tertinggi sebesar **21,76%**.
* **Tenure:** Karyawan dengan masa kerja **0-2 tahun** paling rentan resign.
